# linear-regression-from-scratch

In this project, I discuss the idea behind simple linear regression, I apply it by creating a model from scratch, then I use it on a Kaggle dataset. If you're reading this for educational purposes, I suggest you study the files in the following order:

- The Theory Behind Simple Linear Regression - Method of Least Squares.pdf
- simple_linear_regression.py
- Linear Regression From Scratch.ipynb
